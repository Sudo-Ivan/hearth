Self-hosted chat and calls for the people you actually know.

Instant messaging and VoIP on your own box. A personal fork of Fluxer, tuned for a single host and a small circle of friends and family.

Self-host Source
Why Hearth

Everything a small server needs, nothing it does not.

Podman-first, rootless

Runs unprivileged as a single compose stack. One host, one user, no daemon socket drama. Plain Docker works too.

Reverse-proxy friendly

Sits happily behind nginx, Caddy or Traefik. Let your existing TLS and vhost setup handle the front door.

CrowdSec on the edge

Pairs naturally with a CrowdSec bouncer on the proxy, so scanners and brute-forcers get bounced before they arrive.

Voice and video via LiveKit

Self-hosted LiveKit SFU ships in the stack, so calls stay crisp and your media never touches a third party.

Admin panel built in

Manage users, invites and moderation from a bundled admin UI. No database spelunking required.

AGPL-3.0

Free software end to end. Forked from Fluxer and kept open, so you can read, patch and share every line.

Quickstart

One script, one host, running.

Clone the repo, point the deploy script at an install directory and your domain.

sh 
$ deploy/self-hosting/deploy.sh ~/hearth chat.example.com https://chat.example.com

Full guide, DNS notes and upgrade path live in deploy/self-hosting in the repository.
