This page is made from the help that hearthctl prints, and `hearthctl <command> --help` shows the same text in the terminal.

## Flags for every command

- `--dir string`

  Folder with your instance.

- `-q`, `--quiet`

  Print only errors and results.

- `--verbose`

  Print every step and command.

- `-y`, `--yes`

  Answer yes to every question and never prompt.

## hearthctl admins

Choose who can manage your instance.

### hearthctl admins add

Make an account an admin.

```sh
hearthctl admins add <user>
```

### hearthctl admins remove

Remove admin access from an account.

```sh
hearthctl admins remove <user>
```

### hearthctl admins sign-in-link

Print a link that signs an admin in once.

```sh
hearthctl admins sign-in-link <user>
```

## hearthctl backup

Back up your instance. Hearth pauses while uploads are copied.

```sh
hearthctl backup
```

### hearthctl backup keep

Show or change how many backups hearthctl keeps. After each backup, hearthctl deletes the oldest ones beyond this number, except the backup that hearthctl rollback needs. Pass all to keep every backup.

```sh
hearthctl backup keep [count|all] [flags]
```

- `--json`

  Print JSON.

### hearthctl backup list

List your backups.

```sh
hearthctl backup list [flags]
```

- `--json`

  Print JSON.

### hearthctl backup location

Show the folder hearthctl saves backups in, or pass a full path to save new backups there. Backups that are already saved stay where they are.

```sh
hearthctl backup location [folder] [flags]
```

- `--json`

  Print JSON.

### hearthctl backup verify

Check that a backup is complete and readable.

```sh
hearthctl backup verify <file>
```

## hearthctl branding

Change your instance's name, colour and images.

### hearthctl branding set

Change the name, colour, logo or icon.

```sh
hearthctl branding set [flags]
```

- `--colour string`

  Accent colour as a hex code, like #e5484d.

- `--icon string`

  Image file for the icon.

- `--logo string`

  Image file for the logo.

- `--name string`

  Your instance's name.

## hearthctl config

Read and change Hearth's settings.

### hearthctl config get

Show one setting.

```sh
hearthctl config get <key> [flags]
```

- `--json`

  Print JSON.

- `--reveal`

  Print a secret hearthctl keeps.

### hearthctl config list

List every setting with its value and help.

```sh
hearthctl config list [flags]
```

- `--all`

  Also list every raw setting and the secrets hearthctl generated.

- `--json`

  Print JSON.

### hearthctl config set

Change one or more settings.

```sh
hearthctl config set <key> <value> | <key>=<value>...
```

### hearthctl config unset

Go back to the default for one or more settings.

```sh
hearthctl config unset <key>...
```

## hearthctl doctor

Check your instance and this machine for problems.

```sh
hearthctl doctor [flags]
```

- `--fix`

  Fix the problems hearthctl can fix safely.

- `--json`

  Print JSON.

## hearthctl eject

Writes every setting into the instance folder for docker compose and stops hearthctl from changing the instance. Hearth keeps running. Run hearthctl takeover to hand it back.

```sh
hearthctl eject
```

## hearthctl email

Set up how your instance sends email.

### hearthctl email off

Stop sending email.

```sh
hearthctl email off
```

### hearthctl email set

Set the SMTP server.

```sh
hearthctl email set [flags]
```

- `--from string`

  Sender, like Example Chat \<noreply@chat.example.com>.

- `--host string`

  The SMTP server.

- `--password-file string`

  File with the SMTP password, or - for stdin.

- `--port int`

  The SMTP port. The default is `587`.

- `--tls string`

  How the connection is encrypted (starttls, implicit, opportunistic or none). Picked from the port when left out.

- `--username string`

  The username for the SMTP server.

### hearthctl email test

Send a test email.

```sh
hearthctl email test [address]
```

## hearthctl install

Install Hearth on this machine, or take over an existing install.

```sh
hearthctl install [flags]
```

- `--admin-email string`

  Email address for your admin account.

- `--admin-password-file string`

  File with your admin password, or - for stdin.

- `--admin-username string`

  Username for your admin account.

- `--behind-proxy`

  Serve plain HTTP for your own reverse proxy.

- `--bind string`

  Address your proxy connects to, with --behind-proxy. The default is `127.0.0.1:8080`.

- `--confirm string`

  Your instance's domain, to confirm without a prompt.

- `--delete-old-data`

  Delete Hearth data found on this machine and start fresh.

- `--domain string`

  Address people will use to open your instance, like chat.example.com.

- `--dry-run`

  Show what would happen without changing anything.

- `--engine string`

  Container engine to use (docker or podman).

- `--install-docker`

  Install Docker if it's missing. The default is `true`.

- `--memory-profile string`

  Pin small, medium or large instead of sizing Hearth to this machine on every start.

- `--name string`

  Your instance's name.

- `--no-start`

  Write the files without starting Hearth.

- `--open-firewall`

  Open the ports Hearth needs in ufw or firewalld. The default is `true`.

- `--registration string`

  Who can create an account (invite, approval, open or closed).

- `--setup string`

  Where to create your admin account (terminal or browser).

- `--setup-podman`

  Start Podman's API socket and start Hearth with the machine. The default is `true`.

- `--sign-in string`

  How people sign in (email or username).

- `--skip-email`

  Set up email later.

- `--smtp-from string`

  Sender, like Example Chat \<noreply@chat.example.com>.

- `--smtp-host string`

  The SMTP server.

- `--smtp-password-file string`

  File with the SMTP password, or - for stdin.

- `--smtp-port int`

  The SMTP port. The default is `587`.

- `--smtp-tls string`

  How the connection is encrypted (starttls, implicit, opportunistic or none). Picked from the port when left out.

- `--smtp-username string`

  The username for the SMTP server.

- `--storage-access-key string`

  The object store access key.

- `--storage-bucket-prefix string`

  Text to put before each bucket name, like chat- for chat-hearth.

- `--storage-endpoint string`

  Your own S3-compatible object store, like https://s3.example.com, instead of the bundled one.

- `--storage-path-style`

  Put the bucket in the path of object store addresses instead of the host name. The default is `true`.

- `--storage-public-endpoint string`

  The object store address browsers use, when it differs from --storage-endpoint.

- `--storage-region string`

  The object store region (found from --storage-endpoint when it can be).

- `--storage-secret-key-file string`

  File with the object store secret key, or - for stdin.

- `--take-over`

  Take over Hearth data found on this machine.

- `--voice-ip string`

  Public IP address for voice and video (found automatically).

## hearthctl invites

Manage invite links for new accounts.

### hearthctl invites create

Create an invite link.

```sh
hearthctl invites create [flags]
```

- `--expires string`

  How long the link works, like 12h, 7d or never. The default is `7d`.

- `--label string`

  A note to help you recognise the link.

- `--uses int`

  How many people can use the link, or 0 for no limit. The default is `1`.

### hearthctl invites list

List invite links.

```sh
hearthctl invites list [flags]
```

- `--json`

  Print JSON.

### hearthctl invites revoke

Stop an invite link from working.

```sh
hearthctl invites revoke <id>
```

## hearthctl logs

Show logs from your instance.

The services are web, api, worker, gateway, voice, media, edge, admin, push, database, search, storage, cache, queue and internal.
Without a service, hearthctl shows every service.

```sh
hearthctl logs [service] [flags]
```

- `-f`, `--follow`

  Keep printing new lines.

- `--since string`

  Show lines newer than this, like 10m or 2h.

## hearthctl proxy

Use your own reverse proxy in front of Hearth.

### hearthctl proxy off

Serve HTTPS directly with a certificate from Let's Encrypt.

```sh
hearthctl proxy off
```

### hearthctl proxy on

Serve plain HTTP for your own proxy.

```sh
hearthctl proxy on [flags]
```

- `--bind string`

  Address your proxy connects to, kept when left out (127.0.0.1:8080 the first time).

```sh
hearthctl registration approve <id>
```

### hearthctl registration deny

Turn down a person waiting for approval.

```sh
hearthctl registration deny <id>
```

### hearthctl registration pending

List people waiting for approval.

```sh
hearthctl registration pending [flags]
```

- `--json`

```sh
hearthctl registration set <open|approval|invite|closed>
```

## hearthctl restart

Restart your instance.

```sh
hearthctl restart
```

## hearthctl restore

Restore your instance from a backup. This works on a new machine too. Copy the backup file there and run this command.

```sh
hearthctl restore <file> [flags]
```

- `--confirm string`

  Your instance's domain, to confirm without a prompt.

- `--engine string`

  Move the instance to another engine while restoring (docker).

## hearthctl rollback

Go back to the release you ran before the last upgrade.

```sh
hearthctl rollback [flags]
```

- `--confirm string`

  Your instance's domain, to confirm without a prompt.

- `--dry-run`

  Show what would happen without changing anything.

- `--restore-database`

  Also restore the database from the backup taken before the upgrade.

## hearthctl search

Manage search on your instance.

### hearthctl search reindex

Rebuild every search index from your data, with the messages in every channel and DM. Search shows partial results until it finishes. If a rebuild is already running, hearthctl follows that one, and stopping hearthctl doesn't stop the rebuild.

```sh
hearthctl search reindex [flags]
```

- `--no-wait`

  Start the rebuild and return without waiting for it.

## hearthctl takeover

Hands an instance made by the old installer, by hand with docker compose, or released with hearthctl eject over to hearthctl. Hearth keeps running as it is.

```sh
hearthctl takeover [flags]
```

- `--dry-run`

  Show what would change without changing anything.

## hearthctl uninstall

Remove Hearth from this machine.

```sh
hearthctl uninstall [flags]
```

- `--confirm string`

  Your instance's domain, to confirm without a prompt.

- `--keep-data`

  Keep your data and backups.

## hearthctl upgrade

Upgrade hearthctl and Hearth to the latest release.

```sh
hearthctl upgrade [flags]
```

- `--check`

  Show whether an upgrade is available without changing anything.

- `--dry-run`

  Show what would happen without changing anything.

- `--json`

  Print JSON.

- `--no-backup`

  Skip the backup before upgrading.

- `--prefetch`

  Download the new version and upgrade later.

- `--to string`

  Upgrade to this version, not the latest.

## hearthctl users

Manage accounts on your instance.

### hearthctl users ban

Ban an account.

```sh
hearthctl users ban <user> [flags]
```

- `--delete-messages`

  Also delete their messages.

- `--reason string`

  Why you're banning them, one of spam, scam, harassment, hate, threats, raids, automation, ban-evasion, impersonation, malware, doxxing, intimate-images, explicit-content, adult-content, violence, self-harm, illegal, deception, exploits or report-abuse.

### hearthctl users create

Create an account and print a link to set its password.

```sh
hearthctl users create <username> [flags]
```

- `--admin`

  Make the account an admin.

- `--email string`

  Email address for the account.

### hearthctl users delete

Delete an account and its data.

```sh
hearthctl users delete <user> [flags]
```

- `--confirm string`

  Your instance's domain, to confirm without a prompt.

### hearthctl users disable-mfa

Turn off two-factor authentication for an account.

```sh
hearthctl users disable-mfa <user>
```

### hearthctl users list

List accounts.

```sh
hearthctl users list [flags]
```

- `--admins`

  Only show admins.

- `--json`

  Print JSON.

- `--search string`

  Only show accounts that match this text.

### hearthctl users reset-link

Print a link to set a new password.

```sh
hearthctl users reset-link <user>
```

### hearthctl users show

Show one account.

```sh
hearthctl users show <user> [flags]
```

- `--json`

  Print JSON.

### hearthctl users sign-out

Sign an account out everywhere.

```sh
hearthctl users sign-out <user>
```

### hearthctl users unban

Lift a ban.

```sh
hearthctl users unban <user>
```
